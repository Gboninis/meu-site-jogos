# Meu site de jogos

Vitrine de jogos retrô com o [EmulatorJS](https://github.com/EmulatorJS/EmulatorJS) v4.2.3.
No ar em https://meu-site-jogos-navy.vercel.app

- `index.html`: a vitrine com os cards
- `emulator/player.html`: abre o jogo (no site publicado, o jogo é escolhido no aparelho)
- `capas/`: capas dos jogos (acervo libretro-thumbnails)
- `roms/`: fica vazia no repositório; os jogos ficam só no seu aparelho
- `montar-vercel.sh`: monta a pasta enxuta que vai para a Vercel
